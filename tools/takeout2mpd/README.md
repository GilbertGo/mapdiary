# 구글 테이크아웃 사진 → MPD 여러 날 여행 기록

2026-11-22 사용자 '2018년 산티아고 순례길 사진만 가지고 MPD로 여행기록을 거꾸로 만들 수 있으면 최고!!' → '1번은 하고, 2번은 프랑스길을 중간부터 시작했어 — 레온부터'.

앱에 단추를 더하지 않고, 이 도구가 **MPD 백업 파일**을 만들어요. 앱에서는 이미 있는 '내 MPD → 기록 지키기 · 가져오기 → 백업 불러오기'로 넣어요.
백업 불러오기는 지운 기록·사진(묘비)을 먼저 보고 `photoPut`으로 넣기 때문에, 지운 것은 되살아나지 않아요. 이 내용은 `tests/run.mjs` '테이크아웃 사진 여행' 시험이 확인해요.

## 하는 일
1. 테이크아웃 폴더(압축 푼 것)에서 사진과 짝 .json(찍은 시각 `photoTakenTime`, 위치 `geoData` 또는 `geoDataExif`)을 읽어요. .json이 없으면 사진 속 EXIF를 봐요.
   - EXIF 찍은 시각(`DateTimeOriginal`)은 시간대가 없는 그곳 시계 글자라서 `OffsetTimeOriginal`이 있으면 그것으로, 없으면 `--exif-tz`(기본 `--tz`)로 읽어요. 2018 산티아고 사진 두 장으로 구글 .json 시각과 같음을 확인했어요.
   - EXIF GPS 시각(`GPSTimeStamp`)은 안 써요. 갤럭시 노트8 사진에서 .json보다 1시간씩 어긋났어요. 파일 이름도 안 써요. 저장한 때라 찍은 때와 다를 수 있어요(예: `20181007_224022.jpg`는 실제로 오전 9:04에 찍은 사진).
   - 앨범 폴더와 'Photos from 2018' 폴더에 같은 사진이 두 번 있으면 한 번만 넣어요.
   - 동영상은 아직 빼요(백업 파일이 너무 커져서).
2. 여행 날짜 안의 사진만 골라요. 첫날 앞쪽과 마지막 날 뒤쪽에서 길 25km 밖에서 찍은 사진(공항, 다음 여행지로 가는 길)은 빼요. `--from`·`--to`를 주거나, 없으면 길에서 25km 안에서 찍은 첫 사진부터 마지막 사진까지예요. 현지 날짜(`--tz`, 기본 Europe/Madrid)마다 하루 기록으로 나눠요.
3. 하루 길은 사진 위치를 시간 순으로 이어요. 두 사진이 모두 순례길(`--route`)에서 2km 안이고 앞으로 가는 차례이면, 그 사이는 순례길을 따라가요. 시각은 거리 비율로 나눠요. 그렇지 않으면 곧은 줄로 이어요(보고서 `straight`).
4. 위치 없는 사진은 그 시각에 있었을 길 위 자리에 놓아요.
5. 하루 기록마다 메모(`walkNote`)에 '사진 n장으로 거꾸로 만든 기록 · 길은 짐작'이라고 적어요(출처 나누기 규칙). 출발·도착 마을은 route.json의 `towns`에서 3km 안의 마을로 정해요.
6. 사진은 앱과 같게 줄여요: 큰 것은 1280px JPEG .82, 작은 것은 160px .7.
7. 아이디는 이름·날짜·사진에서 만들어요. 같은 파일을 다시 넣어도 겹치지 않아요.
8. 백업 파일이 `--max-mb`(기본 45MB)를 넘으면 날짜 순으로 여러 파일로 나눠요. 여행 아이디가 같아서, 파일을 차례로 불러오면 한 여행으로 합쳐져요.

## 쓰는 법
```
cd tools/takeout2mpd && npm i
node takeout2mpd.mjs --takeout <압축 푼 Takeout 폴더> --route route.json --name "산티아고 순례길" --out out [--from 2018-09-10 --to 2018-10-05] [--dry]
```
결과물은 `out/MapDiary_YYYYMMDD_01.json …`과 `out/report.json`(날마다 사진 수·위치 있는 사진 수·km·출발→도착·곧은 줄 수, 뺀 것)이에요.

## route.json
모양은 `{ name, pts: [[lat,lng], …], towns: [{ n, lat, lng }] }`이고, `pts`는 길 차례대로예요(출발 → 도착).
OSM 순례길 관계(route=hiking)의 길 조각을 이어 만들어요. 이 클라우드에서는 Overpass가 막혀 있어서, PC 앱 브라우저에서 받아요.
