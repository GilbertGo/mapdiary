# MPD Run 갤럭시워치 앱

휴대폰 없이 시계 혼자 달리기를 기록하는 앱. 시계 GPS로 거리·시간·페이스, 시계 센서로 심박·걸음을 재고, 1km마다 진동과 목소리로 알려 주며 러닝 코치(목표를 이룰지 판단)를 해요. 화면이 꺼져도 기록해요.

## 화면
- 디자인(2026-10-18 새로): 검은 바탕에 흰 큰 숫자(좁은 굵은 글꼴 sans-serif-condensed, 숫자 폭 고정 tnum), 휴대폰 MPD 바닷가 색(산호 #FF8A4C · 하늘 #4FC3F7 · 달성 금색), 테두리 진행 링(자유 달리기면 이번 1km), 알약 딱지, 하트·멈춤·끝내기 아이콘은 그림(이모지 안 씀). 화면이 어두우면 선과 글자만
- 시작: GPS 준비 · 목표(자유/3·5·10km·하프·풀코스/20·30·45·60·90분) · 완주 목표 시간(거리 목표)·목표 거리(시간 목표) · 목소리 코치 켜고 끄기 · 시작 · 지난 기록
- 달리는 중 (옆으로 밀어 넘김): **A안 목표 링** → **B안 네 칸 숫자** → **C안 코치 신호등** → 1km 구간 → 멈춤·끝내기(끝내기는 1.5초 꾹). 마지막으로 본 A·B·C를 기억해요
- 끝내면 저장하고 요약(거리·시간·평균 페이스·심박·케이던스·목표 결과·1km 구간)

## 받는 곳
https://github.com/GilbertGo/mapdiary/releases/download/watch/MPD_run_watch.apk

## 시계에 까는 법 (플레이스토어에 없어서 '무선 디버깅'으로 넣어요)
1. **시계**: 설정 → 시계 정보 → 소프트웨어 정보 → '소프트웨어 버전'을 7번 누르기 (개발자 모드 켜짐)
2. **시계**: 설정 → 개발자 옵션 → 'ADB 디버깅' 켜기, '무선 디버깅' 켜기 (휴대폰과 같은 와이파이에 연결)
3. **휴대폰**: 플레이스토어에서 'Wear Installer 2' 설치, 위 주소에서 MPD_run_watch.apk 받기
4. **시계**: 무선 디버깅 → '새 기기 페어링' → 나온 IP 주소·포트·페어링 코드를 Wear Installer 2에 적기
5. **휴대폰**: Wear Installer 2에서 받은 MPD_run_watch.apk를 골라 설치
6. **시계**: 앱 목록의 MPD Run을 열고 위치·신체 센서·신체 활동·알림을 모두 허용
7. 다 깔았으면 시계의 '무선 디버깅'은 꺼 두세요 (배터리)

새 판은 같은 방법으로 덮어 깔면 기록이 그대로 남아요(늘 같은 서명).

## 앱 안에서 새 판 받기 (0.1.6부터)
- 시작 화면을 열면 GitHub Releases `watch`의 설명 글 '판 0.1.N'을 읽어, 지금 판보다 새 판이 있으면 맨 위에 **'새 판이 있어요 · 0.1.N 설치하기'**가 떠요(`Updater.kt`).
- 누르면 시계가 와이파이로 APK를 받아 설치 창을 띄워요. 처음 한 번은 **'이 앱에서 설치 허용'**(알 수 없는 앱 설치)을 켜야 해요(설정 화면이 저절로 열려요).
- 그래서 Wear Installer는 0.1.6을 처음 깔 때 한 번만 쓰면 돼요. 시작 화면 맨 아래 작은 글씨가 지금 판이에요.
- **지킬 것**: 서명 열쇠(`runapp/debug.keystore`)를 바꾸지 말 것(바꾸면 덮어 깔기가 안 돼 지우고 다시 깔아야 함), 릴리스 설명 글의 '판 0.1.{실행 번호}' 형식을 바꾸지 말 것(versionCode = 실행 번호).

## 만들기
`.github/workflows/watch-apk.yml`이 `watchapp/`가 바뀌면 GitHub에서 APK를 만들어요(main이면 Releases 'watch'에 올림). 서명은 휴대폰 MD Run과 같은 `runapp/debug.keystore`, 앱 ID도 같은 `io.github.gilbertgo.mdrun` (나중에 시계 → 휴대폰으로 기록 넘기기를 하려고).

## 코드
- `Run.kt` — 거리·움직인 시간·현재 페이스·1km 구간·목표·러닝 코치 (휴대폰 index.html의 러닝 코드를 옮김), 저장 모양(Map Diary 백업과 같은 키 + `walkHr`)
- `RunService.kt` — 화면이 꺼져도 GPS·심박·걸음을 받는 기록 도우미(알림 'MD Run 기록 중'), 목소리(TTS)·진동
- `RunView.kt` — 달리는 중 화면 5장 (Canvas로 그림, 둥근 화면 크기에 맞춰 늘고 줄음)
- `MainActivity.kt` — 시작·목표·3·2·1·끝·지난 기록
- `Store.kt` — 기록 파일(`runs/{ID}.json`), 달리는 중 `current.json`, 설정
- `Ambient.kt` — 화면이 어두워져도 이 앱을 계속 보여 줌
